# bvi_way — перенос на GitHub без Git и редактора кода

Этот архив подготовлен для загрузки через обычный браузер. Устанавливать Git, VS Code или другой редактор не нужно.

## Вариант 1 — загрузка через GitHub

1. Откройте [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите **New repository**, задайте название, например `bvi-way`, выберите **Public** и создайте пустой репозиторий. README автоматически не добавляйте.
3. Откройте репозиторий и нажмите **Add file → Upload files**.
4. Распакуйте этот архив на компьютере. Откройте распакованную папку, выделите всё её содержимое и перетащите в окно GitHub. В корне репозитория должны лежать `package.json`, `client` и папка `.github`, а не дополнительная вложенная папка.
5. Внизу страницы нажмите **Commit changes**.

## Включение публикации

В архиве уже есть `.github/workflows/deploy-pages.yml`. После загрузки он автоматически установит зависимости, соберёт сайт и опубликует `dist/public` на GitHub Pages.

После первого Commit откройте **Settings → Pages** и выберите **Source: GitHub Actions**. Затем откройте **Actions** и дождитесь завершения workflow **Deploy bvi_way to GitHub Pages**. После успешного завершения GitHub покажет ссылку на сайт в разделе **Settings → Pages**.

Если репозиторий называется не `bvi-way`, менять код не нужно: workflow сам подставляет имя репозитория в базовый адрес Vite.

## Локальный запуск не обязателен

Для публикации запуск на компьютере не требуется. Если понадобится локальная проверка, нужны Node.js 18+ и pnpm:

```bash
pnpm install
pnpm dev
```

## Что находится внутри

В проекте есть landing page bvi_way с hero-блоком, направлениями, картой маршрута, примерами стоимости олимпиад, предварительной анкетой, FAQ и ссылками на Telegram `@bvishechka`. Форма демонстрирует следующий шаг и ведёт в Telegram; автоматической CRM-интеграции нет. Логотип bvi_way и иллюстрации находятся в `client/public/assets`.

В `ideas.md` описана дизайн-система, а в `spli4_channel_findings.md` сохранён анализ исходных материалов. В MVP не добавлены неподтверждённые отзывы, кейсы, гарантии и реквизиты. Цены отмечены как примеры, требующие уточнения.

Основные ссылки: [канал bvi_way](https://t.me/bvi_way) и [контакт @bvishechka](https://t.me/bvishechka).
