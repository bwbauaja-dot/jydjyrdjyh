- [ ] Добавить README с командами запуска и публикации через GitHub.
- [ ] Передать архив, README и анализ пользователю.

- [ ] Переименовать публичный бренд лендинга в `bvi_way`.
- [ ] Подготовить web-версию предоставленного логотипа с прозрачным фоном.
- [ ] Заменить знак в шапке, hero и footer на логотип bvi_way.
- [ ] Пересобрать GitHub-архив с обновлённым названием и логотипом.
